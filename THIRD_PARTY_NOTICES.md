# External resources and attribution

Repository code and documentation use the [MIT License](LICENSE). Separately downloaded resources retain their own licenses and access terms.

Model implementations and weights are obtained from their authors; [model downloads](docs/models.md) links to each provider. PTB-XL is obtained from [PhysioNet](https://physionet.org/content/ptb-xl/1.0.3/). Follow each provider's terms and citation instructions.

Our preprocessing steps are based on the model authors' repositories, articles, and released configurations. References and experiment-specific choices are listed in [the preprocessing guide](docs/preprocessing/README.md).

Python dependencies are installed separately, including NumPy, SciPy, PyTorch, scikit-learn, WFDB, resampy, and Matplotlib. Model-specific dependencies follow the authors' environment instructions.

[References](docs/references.md) collects dataset, model, method, and software citations. Datasets, pretrained weights, author implementations, experiment results, and generated figures remain local.
